# 001 · 确定性是谱系，不是开关

> **状态**：已采纳
> **锚点**：GAPS AF-01 · AF-02 · `ze_time::clock::ClockForest`
> **被谁取代**：—

## 决策

确定性按「能否从 `(初始态, 输入流)` 重建」分成四层，而不是「有 / 无」两态：

- **L0** `state = f(t)`：任意 seek O(1)。
- **L1** `state = f(t, 输入流)`：任意 seek O(1)——**项目所在层**。
- **L2** `state = fold(seed, 输入流)`：seek O(n)，需要重放，但**仍可复现**。
- **L3** 依赖环境：无保证——**明确拒绝**。

判据只有一条：能否从 `(初始态, 输入流)` 重建。能 ⇒ L2 及以上；不能 ⇒ L3。
求解器、弹簧、粒子、有记忆的递归（`NatRec`）都不是「破坏确定性」，只是 L2 的成员——
**接受 O(n) 的 seek 代价就能进来**。引擎按绑定推导 `SeekKind`（`O1` / `Replay`）并把它留在引擎内部，不进脚本、不进产物。

## 理由

把确定性当布尔会立刻误伤：弹簧与积分器在游戏里是常规需求，用「不许有状态」去拒绝它们，等于用一个能力限制去解决本该由代价模型解决的问题。

分层的好处是**拒绝有了具体理由**：我们拒绝的不是「有状态」，而是「无法从初始态重建」——后者才是真正不可复现的东西。同一个判据还能反过来解释「拿起是 L1，放下是 L2」：两者都可复现，区别只在 seek 代价，因此关掉 O(1) 能力不会让系统变弱，只是变慢。

L1 之所以能承诺 O(1)，靠的是两个结构事实而不是纪律：时间是显式的时钟链（`ClockForest`），状态只在求值期存在、不进产物。一旦这两条被破坏（例如偷偷读墙钟或全局计数器），L1 就退化成 L3——`AF-01` 的第四判据正是用来守这一点的检查项。

## 反例 / 边界

- **predicate + Hold 只有在可分析时才退回 O(1)**：predicate 能化成局部时间区间集时，`Hold` 是纯函数 `f(last_active(t))`；不可分析的 `Hold` 在脚本装配期被显式拒绝。历史产物不受这条保护，仍有静默取错值的风险。
- **含 `NatRec` 的绑定必然是 `Replay`**：递归次数是结构值，不可能跳过前面的步。
- **分层不会消掉环境差异**：字体、libm、GPU、编码器仍在，跨端逐位相同**不做承诺**；同一层内部也分「同目标可复现 / 跨端结构一致 / 跨端逐位相同」三种口径，不能混用。
- **L3 不是「以后再说」**：任何新能力如果无法从初始态重建，就必须先改造它（把环境变成显式输入），而不是先落地再补确定性。

剩余缺口见 GAPS `AI-07` 段。
