# 002 · 计算内核双层模型

> **状态**：已采纳
> **锚点**：GAPS AL-03 · AL-04 · `ze_comb::program::Step`
> **被谁取代**：—

## 决策

计算内核分两层，所有算子必须归属其中一层：

- **连续层 C**：`f: ℝⁿ → V`，逐点独立（pointwise），O(1)，纯函数。
- **离散层 D**：`value(k) = f(value(k-1), input(k))`，结构递归，带**显式 Cache 参数**。

配套三条：

1. **时间只是 n=1 的一个实例**：通道是「多维连续变量」，时间只是其中最常见的那一维。
2. **`pointwise` 是声明 + 污染传播**：与 `Send`/`Sync` 的 auto trait 模式同构，污染取并集。
3. **Cache 是显式参数**：求值签名是 `eval(state, input) -> (state', value)`，状态可序列化、可清空、可重建。

符号化简的目标因此不是「跑得更快」，而是**层间迁移**：把非 pointwise 的表达式变回 pointwise（例如 `∫sin` 有闭式解，就从离散层退回连续层），从而把 seek 从 O(n) 变回 O(1)。

## 理由

两层模型解决的是同一件事的两种极端：连续层保证「任意帧独立可算」，离散层保证「有记忆的演化也能表达」。如果只保留连续层，弹簧 / 积分器 / 粒子全都要被拒绝；如果只保留离散层，所有动画都要从头重放——代价无法接受。

Cache 做成显式参数，是为了让「清空重算逐位相同」从一条团队纪律变成**类型事实**：状态不在隐藏的 `self` 里，调用方随时可以丢掉它重建。这也让离散层的结果可序列化，从而能进产物。

污染传播必须保守：把非 pointwise 误判成 pointwise 会算错值（而且是静默的），把 pointwise 误判成非 pointwise 只会慢一点。因此在拿不准时一律标脏。

## 反例 / 边界

- **闭式解不是总能找到**：层间迁移只在存在闭式表达式时成立；数值积分只能留在离散层。
- **状态不可序列化的算子不能进产物**：如果某个离散层成员的状态含指针、GPU 资源或外部句柄，它就无法满足「清空重算」，此时要么改造成纯数据，要么不进产物。
- **多维连续变量不等于多维时钟**：时钟链只覆盖仿射组合（`rate × t + shift`），非仿射的时间变换必须降级成离散层。
- **pointwise 的传播是表达式级的，不是函数级的**：一个算子在某个参数上 pointwise，不代表整条链 pointwise；报告必须给到污染源，否则无法定位。
